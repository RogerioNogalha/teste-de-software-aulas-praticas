# Avaliação automática nos laboratórios

## Individual

Cada estudante aceita o convite do GitHub Classroom e recebe um repositório privado. A correção executa a cada `push`.

| Critério automático | Pontos sugeridos |
|---|---:|
| Instalação e execução da aplicação | 1,0 |
| Testes unitários e casos-limite | 3,0 |
| Testes de integração/API | 2,0 |
| Cobertura mínima e regressão | 1,5 |
| Qualidade estática | 1,0 |
| Pipeline completo | 1,5 |

## Grupo

Cada equipe recebe um repositório compartilhado. O produto pode ser corrigido automaticamente, mas a nota individual considera issues, commits, pull requests, revisão por pares, apresentação e domínio do código.

## Regras

- A pontuação automática é evidência, não a nota integral.
- Testes e workflows são monitorados como caminhos protegidos.
- Falhas devem permanecer visíveis para promover diagnóstico e melhoria.
- Entregas com IA devem preencher `REGISTRO_IA.md`.
- O professor poderá solicitar explicação oral de qualquer alteração.
