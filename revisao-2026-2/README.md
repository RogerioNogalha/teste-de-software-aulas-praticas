# Teste de Software — Aulas Práticas 2026/2

Revisão pedagógica do material utilizado no semestre anterior, alinhada ao plano de ensino de **Testes, Métricas e Qualidade de Software** do curso de Análise e Desenvolvimento de Sistemas.

O roteiro histórico baseado em *Test-Driven Development with Python* continua sendo a trilha de desenvolvimento da aplicação TODO. A oferta 2026/2 acrescenta GitHub Classroom, PyTest, métricas, integração contínua, testes de API, automação de interface, revisão por pares e uso responsável de IA.

## Organização de cada aula

1. Preparação por aula invertida.
2. Síntese teórica e diagnóstico inicial.
3. Demonstração curta do professor.
4. Laboratório individual ou em equipe.
5. `commit`, `push` e execução automática dos testes.
6. Análise das evidências e fechamento.

## Sequência

| Aula | Teoria | Prática | Evidência |
|---|---|---|---|
| 1 | Qualidade, níveis de teste, TDD e Git | Primeiro ciclo vermelho–verde–refatora | Histórico de commits e PyTest |
| 2 | Técnicas de projeto de testes e regressão | Interação, parametrização e banco de dados | Casos de teste e suíte automatizada |
| 3 | Integração, isolamento e testabilidade | API, persistência, fixtures e test doubles | Pipeline e relatório de falhas |
| 4 | Métricas e qualidade interna | Cobertura, análise estática e refatoração | Relatório crítico de métricas |
| 5 | Qualidade contínua e automação | GitHub Actions, API e interface web | Pull request com pipeline aprovado |
| 6 | IA aplicada a testes e Projeto Integrador | Geração e validação de testes, release e retrospectiva | Registro de IA e relatório final |

## Entregas no GitHub Classroom

- Atividades individuais geram um repositório privado por estudante.
- Atividades em grupo geram um repositório privado por equipe.
- PyTest e GitHub Actions executam a cada envio.
- A nota automática é complementada por rubrica de autoria, análise crítica e colaboração.
