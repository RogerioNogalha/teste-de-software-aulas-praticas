# Aula 1 — Qualidade, TDD e fluxo Git

## Aula invertida

Ler `conceitos.md`, revisar os capítulos 1 a 3 da trilha do livro e responder no Moodle: qual a diferença entre teste unitário, funcional e de aceitação?

## Teoria em sala

- qualidade de produto e de processo;
- verificação e validação;
- níveis de teste e pirâmide de testes;
- ciclo vermelho–verde–refatora;
- rastreabilidade por issues, commits e pull requests.

## Laboratório

1. Aceitar a atividade individual no Classroom.
2. Clonar o repositório com GitHub Desktop ou Git.
3. Executar a suíte inicial e registrar a falha esperada.
4. Implementar o menor comportamento necessário.
5. Refatorar mantendo a suíte verde.
6. Abrir pull request de entrega.

## Evidências

- pelo menos três commits coerentes com o ciclo TDD;
- pipeline aprovado;
- breve análise da primeira falha encontrada.
