# Aula 3 — Integração, API e test doubles

## Aula invertida

Revisar os capítulos 6 e 7 da trilha do livro e comparar stub, fake, mock e spy.

## Teoria em sala

- fronteiras de integração;
- testabilidade, acoplamento e injeção de dependência;
- contrato de API e códigos HTTP;
- quando usar ou evitar mocks.

## Laboratório

- isolar banco e serviços externos;
- criar testes de integração para uma rota da aplicação;
- exercitar a API com Postman ou cliente equivalente;
- implementar um test double e justificar sua escolha.

## Evidências

Testes unitários e de integração separados por marcadores, coleção de API e justificativa técnica do double utilizado.
